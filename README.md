## How I work

- **I measure before I optimize.** Timing logs took one step of RokBot from 40–120 s to 10–28 s.
- **A bug gets a test first**, so it cannot come back unnoticed.
- **Unknown never counts as success.** If my tools cannot see something, they say so.
- **I write decisions down**, so the next person does not repeat the mistake.
